# Apa Itu Screen Reader, dan Siapa yang Menggunakannya?

`Screen reader` adalah program `assistive technology` yang membantu para tunanetra dan orang-orang dengan gangguan penglihatan (`visually impaired`) dalam menggunakan komputer dan perangkat seluler (`mobile devices`).

`Screen reader` bukan sekadar alat bagi para tunanetra dan individu dengan gangguan penglihatan untuk mengakses komputer dan perangkat seluler.

Alat-alat ini memberdayakan individu-individu tersebut untuk mengakses pendidikan, peluang kerja, dan media sosial. Hal ini memastikan inklusi digital (`digital inclusion`) dan meningkatkan kemampuan mereka untuk berpartisipasi secara penuh dalam masyarakat.

Ada kesalahpahaman umum bahwa `screen reader` adalah perangkat `text-to-speech`.

Namun, `text-to-speech` hanyalah salah satu fitur dari sebuah `screen reader`. Beberapa `screen reader` bahkan merender teks ke dalam output `braille` alih-alih suara ucapan (`speech`).

Selain `text-to-speech` dan output `braille`, fitur penting lainnya dari `screen reader` adalah alat bantu navigasi dan bantuan penjelajahan web (`web browsing assistance`).

Program `screen reader` juga tidak hanya dibuat untuk tunanetra dan orang dengan gangguan penglihatan. Individu penderita disleksia (`dyslexic`) dan orang-orang dengan disabilitas kognitif juga menggunakan `screen reader`. Semua sistem operasi (`operating system`) populer di luar sana memiliki `screen reader` bawaan (`built-in`).

`macOS` dan `iOS` keduanya memiliki `VoiceOver` bawaan. Anda dapat mengaktifkannya di komputer Anda dengan menekan `CMD` + `F5`. Anda dapat mengaksesnya di iPhone melalui *Settings*.

Komputer `Windows` memiliki `Narrator` bawaan. Anda dapat menyalakannya dengan menekan `WIN` + `CTRL` + `ENTER`. NonVisual Desktop Access (`NVDA`) dan Job Access With Speech (`JAWS`) juga tersedia untuk komputer `Windows`. `NVDA` bersifat gratis dan `open-source`, sedangkan `JAWS` berbayar.

`Linux` memiliki *Orca* untuk lingkungan desktop (`desktop environment`) dan *Speakup* untuk terminal `Linux`.

Ponsel `Android` memiliki `TalkBack` bawaan. Anda dapat mengaktifkannya dengan mengakses *Settings > Special Function > Accessibility > Talkback.*

Beberapa perangkat `Android` juga memiliki `Ella` dan `Select to Speak` bawaan.

Salah satu tantangan utama bagi para pengguna `screen reader` adalah banyak pengembang perangkat lunak (`software developers`) yang tidak merancang produk mereka dengan mempertimbangkan keramahan `screen reader` dan `accessibility`.

Meskipun `accessibility` merupakan topik yang luas, setiap pengembang perlu belajar bagaimana membuat perangkat lunak web mereka dapat diakses oleh para tunanetra dan orang-orang dengan gangguan penglihatan, serta kelompok penyandang disabilitas lainnya.

Hal ini menunjukkan empati dan komitmen terhadap inklusivitas, memastikan bahwa semua pengguna dapat merasakan manfaat dari karya mereka.
