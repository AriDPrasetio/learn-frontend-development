# Apa Peran Meta Description, dan Bagaimana Pengaruhnya terhadap SEO?


`SEO`, atau *Search Engine Optimization* (Optimasi Mesin Pencari), adalah sebuah praktik yang mengoptimalkan halaman web agar menjadi lebih terlihat dan berperingkat lebih tinggi di mesin pencari. Salah satu cara untuk meningkatkan `SEO` situs Anda adalah dengan memberikan deskripsi singkat untuk halaman web menggunakan `element` `meta`. Berikut adalah contoh penggunaan `element` `meta` untuk menyetel deskripsi halaman bagi situs berkebun:

```html
<meta
  name="description"
  content="Discover expert tips and techniques for gardening in small spaces, choosing the right plants, and maintaining a thriving garden."
/>

```

Menyetel `attribute` `name` ke `description` memastikan bahwa browser, mesin pencari, dan alat bantu web lainnya menginterpretasikan metadata ini secara benar. `Attribute` `content` adalah tempat di mana Anda akan menempatkan deskripsi Anda. Sangat disarankan agar Anda menjaga deskripsi tetap singkat dan padat. Hal ini karena mesin pencari sering kali memotong (*truncate*) deskripsi berdasarkan tata letak halaman hasil pencarian.

Mirip dengan tipe `element` `meta` lainnya, deskripsi `meta` tidak akan terlihat pada halaman web itu sendiri. Salah satu tempat di mana deskripsi halaman dapat ditemukan adalah pada cuplikan (*snippet*) halaman hasil mesin pencari. Berikut adalah beberapa contoh cuplikan hasil halaman untuk *subreddit* dan repositori GitHub milik freeCodeCamp:

```html
r/freeCodeCamp: This is the official subreddit for the freeCodeCamp.org community. Learn to
code for free together with millions of other people...

```

```html
Our full-stack web development and machine learning curriculum is completely free and self-
paced. We have thousands of interactive coding challenges to help you...

```

Dalam contoh-contoh tersebut, setiap deskripsi halaman terletak tepat di bawah tautan situs. Dalam hitungan detik, pengguna bisa mendapatkan gambaran umum tentang isi halaman dan memutuskan apakah akan mengklik tautan tersebut untuk informasi lebih lanjut.

Meskipun deskripsi `meta` tidak akan secara langsung memengaruhi peringkat suatu situs di mesin pencari, memiliki deskripsi yang menarik dan tepat dapat mendatangkan lebih banyak kunjungan (*traffic*) ke situs web Anda.
