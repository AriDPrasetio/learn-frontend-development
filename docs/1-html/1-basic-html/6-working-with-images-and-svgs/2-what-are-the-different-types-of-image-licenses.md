# Apa Saja Berbagai Jenis Lisensi Gambar, dan Bagaimana Cara Kerjanya?

Gambar (`image`) dianggap sebagai kekayaan intelektual (*intellectual property*). Ini berarti gambar dilindungi oleh peraturan hak cipta (*copyright*), yang paling sering dimiliki oleh penciptanya. Secara *default*, gambar dirilis sebagai *all rights reserved* (seluruh hak cipta dilindungi undang-undang). Pencipta, atau terkadang penerbit, memegang seluruh hak cipta atas gambar tersebut.

Ini berarti Anda tidak dapat menggunakannya di halaman web Anda kecuali Anda melakukan salah satu dari tiga hal: memperoleh izin tertulis dari pemegang hak cipta, membeli lisensi (`license`) dari pemegang hak cipta, atau menyertakan gambar dengan cara yang termasuk dalam penggunaan wajar (*fair use*).

Poin ketiga tersebut agak rumit. Penggunaan wajar (*fair use*) mengharuskan penggunaan gambar oleh Anda bersifat terbatas sekaligus transformatif. Beberapa contoh penggunaan wajar adalah mengomentari atau mengulas karya seni tersebut atau membuat parodi dari gambar tersebut.

Beberapa gambar mungkin dirilis di bawah lisensi permisif (*permissive license*), seperti lisensi Creative Commons, atau lisensi `BSD` yang digunakan freeCodeCamp. Gambar-gambar ini tersedia untuk digunakan di situs web Anda, tetapi Anda perlu membaca lisensinya untuk memahami aturan yang harus Anda patuhi saat menggunakan gambar-gambar tersebut. Misalnya, Anda mungkin diwajibkan untuk membuat situs web Anda menjadi *open source*, atau Anda mungkin tidak diizinkan untuk memodifikasi gambar tersebut dengan cara apa pun.

Akhirnya, beberapa gambar mungkin dirilis ke ranah publik (*public domain*). Gambar di bawah *public domain* tidak memiliki hak cipta yang melekat padanya dan bebas digunakan tanpa batasan apa pun. Gambar yang dilisensikan secara khusus di bawah lisensi Creative Commons 0 dianggap sebagai *public domain*.

Sebagian besar mesin pencari (*search engine*) memungkinkan Anda memfilter hasil gambar berdasarkan lisensi. Ada juga situs-situs seperti Pixabay dan Unsplash, yang menawarkan gambar gratis untuk digunakan. Selalu perhatikan hak cipta dan lisensi saat Anda menggunakan gambar di situs web Anda.

Apa lisensi *default* untuk gambar?

- [x] All rights reserved
- [ ] Permissive license
- [ ] Public Domain
- [ ] Creative Commons

Lisensi manakah yang merilis karya ke ranah publik (*public domain*)?

- [ ] MIT
- [ ] BSD
- [ ] Creative Commons
- [x] Creative Commons 0

Bagaimana cara Anda menemukan gambar yang diizinkan untuk Anda gunakan?

- [ ] Cari gambar di Google dan gunakan secara bebas.
- [x] Gunakan situs web seperti Pixabay atau Unsplash.
- [ ] Gunakan gambar apa pun dari media sosial asalkan Anda memberikan atribusi.
- [ ] Anda dapat menggunakan gambar apa pun asalkan tidak memiliki *watermark*.
