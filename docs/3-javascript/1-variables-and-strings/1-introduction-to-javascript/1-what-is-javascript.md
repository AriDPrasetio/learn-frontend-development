# Apa Itu JavaScript, dan Bagaimana Cara Kerjanya dengan HTML dan CSS?

`JavaScript` adalah `programming language` yang hebat yang menghadirkan interaktivitas dan perilaku dinamis ke situs web.

Sementara `HTML` dan `CSS` digunakan untuk menyusun konten dan mengatur gaya `element` pada sebuah halaman, `JavaScript` melangkah lebih jauh dari itu dengan mengaktifkan fungsionalitas yang lebih kompleks, seperti menangani `user input`, menganimasikan `element`, dan bahkan membangun aplikasi web yang lengkap.

Sebagai contoh, ketika Anda mengklik sebuah tombol, mengirim formulir, atau mengarahkan kursor ke menu, `JavaScript` menentukan bagaimana halaman tersebut berperilaku.

Berikut adalah contoh bagaimana ketiganya bekerja bersama:

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    h1 {
      color: green;
    }
  </style>
</head>
<body>
  <h1>Hello, World!</h1>
  <button onclick="alert('Button clicked!')">Click me</button>
</body>
</html>
```

Dalam contoh ini, `HTML` digunakan untuk mendefinisikan konten: sebuah `heading` (`element` `h1`) dan sebuah tombol (`element` `button`).

`CSS` digunakan untuk menerapkan gaya pada `heading`, seperti membuat teks berwarna hijau. `JavaScript` digunakan untuk menampilkan pesan peringatan (`alert message`) saat tombol diklik.

Kesimpulannya, `HTML` menyediakan struktur, `CSS` menambahkan gaya, dan `JavaScript` mengaktifkan perilaku, menciptakan pengalaman web yang lengkap dan interaktif.

## Pertanyaan (Questions)

Peran apa yang dimainkan `JavaScript` dalam `web development` dibandingkan dengan `HTML` dan `CSS`?

- `JavaScript` menyediakan struktur untuk `webpage` dan memastikan bahwa `code` Anda bebas dari `error`.
- `JavaScript` menyediakan `styles` untuk `web page` dan secara otomatis memformat `code` Anda.
- `JavaScript` menyediakan fungsionalitas interaktif dan perilaku dinamis untuk `web page`.
- `JavaScript` hanya digunakan untuk membuat animasi tingkat lanjut untuk `web applications`.

Bagaimana `JavaScript` biasanya berinteraksi dengan `HTML` dan `CSS` pada `webpage`?

- `JavaScript` menambahkan lebih banyak `styles` ke file `CSS` dan lebih banyak `element` ke file `HTML`.
- `JavaScript` membuat versi baru `HTML` untuk halaman tersebut sehingga `code` `HTML` Anda akan berjalan lebih cepat.
- `JavaScript` berinteraksi dengan halaman untuk mengubah `content` dan `styles` secara dinamis.
- `JavaScript` hanya berfungsi di `back-end` dan jarang digunakan di `front-end`.

Manakah dari berikut ini yang benar tentang hubungan antara `JavaScript`, `HTML`, dan `CSS`?

- `HTML` adalah `programming language` dan `CSS` adalah `stylesheet language`, sedangkan `JavaScript` adalah `markup language`.
- `HTML` adalah `markup language` dan `CSS` adalah `stylesheet language`, sedangkan `JavaScript` adalah `programming language`.
- `JavaScript` dapat menggantikan `HTML` dan `CSS`.
- `JavaScript` tidak berfungsi dengan `HTML` dan `CSS`.
