# 🚀 Roadmap JavaScript freeCodeCamp v9 (Pareto Edition)

Repositori ini memuat **Roadmap dan Kurikulum Ringkas JavaScript berdasarkan Prinsip Pareto (80/20)** yang disarikan langsung dari kurikulum resmi **freeCodeCamp v9**.

Tujuan utama dari versi ini adalah memfilter **80% materi teoritis yang jarang digunakan pemula** dan memusatkan energi pada **20% konsep inti berdaya ungkit tinggi (*high-leverage core*)** yang menyumbang **80% hasil nyata** dalam pengembangan aplikasi web modern.

---

## 🎯 Filosofi 80/20

> [!IMPORTANT]
> **Prinsip Pareto**: 20% usaha/konsep menghasilkan 80% dampak/hasil.  
> Dalam konteks kurikulum JavaScript freeCodeCamp v9 yang memiliki 26 modul teoretis dan laboratorium, Anda **tidak perlu menguasai seluruh 26 modul secara mendalam di awal** untuk mulai membangun aplikasi web interaktif atau mempelajari *framework* modern seperti React atau Vue.

---

## 🗺️ Peta Klasifikasi 3 Tingkat (*3-Tier Architecture*)

Kurikulum 26 modul freeCodeCamp v9 diklasifikasikan ke dalam 3 tingkatan prioritas:

| Tingkat | Kategori | Alokasi Waktu | Modul FCC v9 yang Dicakup | Dampak Nyata |
| :--- | :--- | :---: | :--- | :--- |
| **🟢 Fase 1** | **High-Leverage Core** | **50%** | Modul 1, 2, 3, 4, 5, 8, 9, 25 | 80% kapabilitas manipulasi data, interaktivitas `DOM`, dan konsumsi REST API. |
| **🟡 Fase 2** | **Pragmatic Bridge** | **30%** | Modul 10, 11, 12, 13, 17, 18 | Menyelesaikan fitur web nyata: validasi form, penyimpanan `localStorage`, inspeksi `bug`, dan aksesibilitas (`A11y`). |
| **🔴 Fase 3** | **Deferred CS Topics** | **20% (Nanti)** | Modul 15, 16, 19, 20, 21, 22, 23, 24 | Materi teoretis/akademis (pohon, graf, rekursi mendalam, *dynamic programming*); dipelajari saat persiapan *technical interview*. |

## ⚖️ Standar Penulisan & Format

Dokumentasi ini ditulis dengan standar:
- **GitHub Flavored Markdown (GFM)**: Menggunakan tabel, *callouts/alerts* (`> [!NOTE]`, `> [!WARNING]`), dan blok kode berwarna.
- **Konsistensi Terminologi**: Seluruh istilah teknis baku (`variable`, `function`, `arrow function`, `array`, `object`, `scope`, `closure`, `DOM`, `Promise`, `async`/`await`, `fetch`) dibungkus tanda *backtick* tanpa diterjemahkan secara harfiah.
- **Navigasi Sekuensial**: Setiap berkas memiliki navigasi sebelum dan sesudah di bagian akhir dokumen.
