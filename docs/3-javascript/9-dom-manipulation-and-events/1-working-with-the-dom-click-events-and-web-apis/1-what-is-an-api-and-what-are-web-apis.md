# Apa Itu API, dan Apa Itu Web API?

Mari kita pelajari tentang `API` dan mengapa mereka sangat penting untuk pengembangan web. `API` adalah singkatan dari *Application Programming Interface*. `API` menetapkan seperangkat aturan dan protokol yang memungkinkan aplikasi perangkat lunak berkomunikasi satu sama lain dan bertukar data secara efisien.

Anda dapat menganggapnya sebagai konstruksi yang memungkinkan pengembang membuat fungsionalitas yang lebih kompleks berdasarkan blok penyusun (*building blocks*) yang lebih sederhana yang telah diimplementasikan sebelumnya.

Ada berbagai jenis `API`. `Web API` dirancang secara khusus untuk aplikasi web. Terdapat berbagai jenis `Web API` untuk pengembangan `JavaScript` di sisi klien (*client-side*). Mereka bukan merupakan bagian dari `JavaScript` itu sendiri.

Jenis-jenis `API` ini sering kali dibagi menjadi dua kategori utama: `Browser API` dan `Third-party API` (API pihak ketiga).

`Browser API` mengekspos data dari peramban (*browser*). Sebagai seorang pengembang web, Anda dapat mengakses dan memanipulasi data ini menggunakan `JavaScript`.

Mereka juga menyediakan akses ke berbagai fungsionalitas, seperti memanipulasi struktur situs web, menangani peristiwa (*event*), bekerja dengan penyimpanan (*storage*), dan berkomunikasi dengan jaringan (*network*).

Beberapa contoh `Browser API` yang umum digunakan meliputi:

- **DOM API**, yang dapat Anda gunakan untuk memanipulasi elemen-elemen `HTML`, gaya (*styles*), dan atributnya. Anda akan mempelajari lebih banyak tentang `DOM` pada pelajaran-pelajaran berikutnya. Ini adalah konsep inti dalam pengembangan web.
- **Storage API**, untuk menyimpan data secara lokal pada perangkat pengguna.
- Dan masih banyak lagi.

Terdapat berbagai `Browser API` yang dapat Anda gunakan untuk menangani interaksi pengguna dan untuk mendapatkan informasi lebih lanjut dari peramban, seperti lokasi pengguna saat ini (*current location*).

Anda juga dapat bekerja dengan jenis elemen lainnya, seperti video dan audio.

`Browser API` dapat menjadi alat yang sangat membantu untuk membangun aplikasi web yang andal. Mereka sudah terpasang secara bawaan di dalam peramban (*built into the browser*).

Namun Anda juga dapat menggunakan `Third-party API` (API pihak ketiga), yang tidak terpasang secara bawaan di dalam peramban. Untuk menggunakannya, Anda perlu mengambil `code` mereka dengan cara tertentu. Biasanya, mereka dilengkapi dengan dokumentasi terperinci yang menjelaskan cara menggunakan layanan mereka.

Sebuah contoh adalah `Google Maps API`, yang dapat Anda gunakan untuk menampilkan peta interaktif di situs web Anda.

Ada berbagai jenis `Third-party Web API`, termasuk `Weather API` (cuaca), `Social Media API`, `Payment API` (pembayaran), `Data API`, `Translation API` (terjemahan), dan banyak lagi. Anda hanya perlu menemukan `API` yang sesuai dengan kebutuhan Anda.

`Web API` adalah alat penting untuk membangun aplikasi web modern yang dapat berinteraksi dengan berbagai layanan dan sumber data. Dengan mempelajari cara memanfaatkan kekuatannya, Anda akan memperluas toolkit Anda untuk membuat situs web yang dinamis dan menarik.

## Pertanyaan (Questions)

### Pertanyaan 1

Apa tujuan utama dari sebuah `API`?

- [ ] Membuat bahasa pemrograman baru.
- [ ] Menyediakan antarmuka pengguna (*user interface*) untuk aplikasi.
- [x] Memungkinkan komunikasi antar aplikasi perangkat lunak yang berbeda.
- [ ] Menyimpan dan mengelola data.

### Pertanyaan 2

Apa perbedaan antara `API` umum dan `Web API`?

- [ ] `API` umum hanya digunakan untuk aplikasi web, sedangkan `Web API` dapat digunakan untuk semua jenis aplikasi.
- [x] `Web API` dirancang secara khusus untuk berinteraksi dengan peramban web (*web browsers*) dan server.
- [ ] Tidak ada perbedaan antara `API` umum dan `Web API`.
- [ ] `API` umum digunakan untuk komunikasi eksternal dalam aplikasi, sedangkan `Web API` digunakan untuk komunikasi internal.

### Pertanyaan 3

Bagaimana `Web API` menyederhanakan pengembangan aplikasi web?

- [ ] Dengan menyediakan antarmuka pengguna (*user interface*) yang sudah jadi.
- [ ] Dengan menghilangkan kebutuhan akan bahasa pemrograman.
- [x] Dengan menawarkan cara-cara standar untuk mengakses dan memanipulasi data serta fungsionalitas.
- [ ] Dengan mengotomatiskan seluruh proses pengembangan.
