# 📖 Rangkuman: Tujuan dan Cara Kerja Function

## 1. Uji Ingatan (Active Recall)
> Coba jawab dulu di dalam kepala sebelum membuka jawabannya!

<details><summary><strong>1. Apa tujuan utama digunakannya sebuah function dalam pemrograman?</strong></summary><br>

Tujuan utamanya adalah agar potongan `code` dapat dipanggil dan digunakan kembali untuk melakukan tugas tertentu atau menghitung sebuah `value`.

</details><br>

<details><summary><strong>2. Apa perbedaan antara parameter dan argument pada function?</strong></summary><br>

`parameter` bertindak sebagai `placeholder` untuk `value` yang akan diteruskan ke dalam `function` saat ia dipanggil. Sementara `argument` adalah `value` aktual yang diteruskan ke `function` saat pemanggilan.

</details><br>

<details><summary><strong>3. Apa fungsi dari return statement di dalam sebuah function?</strong></summary><br>

`return` statement punya dua fungsi: mengirim nilai balik ke pemanggil function, dan menghentikan eksekusi function saat itu juga.

</details><br>

<details><summary><strong>4. Apa itu anonymous function dan bagaimana cara menyimpannya?</strong></summary><br>

Sebuah `anonymous function` adalah `function` tanpa nama. Kamu bisa membuatnya dan menyimpannya ke dalam sebuah `variable` untuk digunakan nanti.

</details><br>

<details><summary><strong>5. Apa yang terjadi jika sebuah parameter memiliki default value namun pemanggil function tidak menyertakan argument untuknya?</strong></summary><br>

Parameter tersebut akan otomatis memakai `default value`-nya.

</details><br>

> [!IMPORTANT]
> Menguasai `function` sangat krusial karena ia adalah pondasi utama dalam menciptakan arsitektur `code` yang `modular` dan `reusable`.
