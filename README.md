# Learn Frontend Development (freeCodeCamp) 🚀

Repositori ini didedikasikan sebagai repositori dokumentasi pembelajaran dan **salinan materi teori kurikulum Frontend Development dari [freeCodeCamp](https://www.freecodecamp.org/) dalam Bahasa Indonesia**.

Materi disajikan secara *verbatim* (akurat kata demi kata) dan terstruktur rapi ke dalam Bahasa Indonesia guna memudahkan pemahaman konsep dasar pemrograman web tanpa menghilangkan esensi serta kedalaman penjelasan teknis aslinya.

---

## 🎯 Fokus & Karakteristik Materi

- **Salinan Teori Berbahasa Indonesia**: Menyediakan terjemahan materi teori kurikulum resmi freeCodeCamp yang lengkap dan mudah dipahami.
- **Integritas Materi Asli**: Mempertahankan 100% struktur orisinal, mencakup contoh kode, ilustrasi konsep, tabel, hingga kuis evaluasi (*Questions*) di setiap topik.
- **Konsistensi Terminologi Teknis**: Istilah pemrograman baku (seperti `variable`, `string`, `function`, `array`, `scope`) tetap dipertahankan menggunakan format kode (*inline backtick*) agar pembaca terbiasa dengan standar industri global.
- **Navigasi Sekuensial**: Setiap dokumen materi dilengkapi tautan navigasi topik sebelum (*Previous*) dan topik berikutnya (*Next*) untuk pengalaman belajar yang berurutan.

## 📖 Format Pembelajaran pada Setiap Topik

Setiap berkas materi di bawah direktori `docs/` disusun dengan struktur:
1. **Penjelasan Teori**: Ulasan konsep lengkap beserta blok kode ilustrasi.
2. **Pertanyaan & Kuis (*Questions*)**: Pilihan jawaban evaluasi pemahaman materi.
3. **Navigasi Antar Halaman**: Tautan `⬅️ Sebelumnya` dan `Selanjutnya ➡️` di bagian akhir untuk kelancaran membaca sekuensial.
