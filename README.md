# Learn Frontend Development (freeCodeCamp) 🚀

Repositori ini didedikasikan sebagai tempat penyimpanan catatan pembelajaran, rangkuman teori, dan riwayat (*history*) kode latihan dari kurikulum Frontend Development di **freeCodeCamp**.

## 📌 Latar Belakang & Konteks

Kurikulum pembelajaran dalam repositori ini mencakup:
- [ ] HTML
- [ ] CSS
- [x] JavaScript (Fokus Saat Ini)
- [ ] Front End Development Libraries (React, dsb.)

**Catatan Khusus:** 
Materi mengenai **HTML** dan **CSS** sebenarnya sudah saya pelajari sebelumnya, sehingga awalnya tidak terlacak (*untracked*) di repositori ini. Oleh karena itu, aktivitas repositori saat ini akan langsung berfokus pada kurikulum **JavaScript**. Catatan teori maupun kode latihan terkait HTML dan CSS akan diarsipkan kembali ke dalam repositori ini secara bertahap ke depannya.

## 📂 Struktur Repositori

- `docs/`: Berisi catatan teori dan ringkasan konsep yang dipelajari dari modul-modul freeCodeCamp.
- Latihan dikerjakan langsung di platform freeCodeCamp, dan riwayat kodenya akan disimpan di dalam repositori ini sebagai rekam jejak.
